# HTML Tables 

## What is Table ?
- Arrangement of data in rows & columns 
- The smallest unite of Table is a cell.
- We keep data in cell.
- We have a tag called `table`, we use to create our tbales via this tag.
```html
<table></table>
```
## `thead` Tag

- Use to insert heading of a table
```html
<table>
    <thead>My Heading</thead>
</table>
```
## `tbody` Tag

- Use to insert body of a table
```html
<table>
    <tbody>My body</tbody>
</table>
```
## `tfoot` Tag

- Use to insert some summerization of a table
```html
<table>
    <tfoot>My Footer</tfoot>
</table>
```
## `tr` Tag

- Use to insert rows in a table
```html
<table>
    <tbody>
        <tr></tr>
    </tbody>
</table>
```
## `td` Tag

- Use to insert data in rows 
```html
<table>
    <tbody>
        <tr>
            <td></td>
        </tr>
    </tbody>
</table>
```
## `th` Tag

- Use to insert data in table header
```html
<table>
    <thead>
        <th></th>
    </thead>
</table>
```
