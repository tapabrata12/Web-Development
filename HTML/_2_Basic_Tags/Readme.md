# Tags

### What is HTML Tags ?

- Tags are Markup entity [Speacial words] by which we can provide our HTML content, 
    - A structure
    - A meaning
    - A formatting
    - Content can be anything (Audio,video,etc) 


- Three types of tags we have 
    - Semantics Tags 
    ```html
    <h1> -> <h6>
    <p> 
    <a>
    <ul> and <ol>
    <table> <tr> <td>
    <img>
    <form>
    <input> 
    ```
    - Structure Tags
    ```html
    <html>
    <head>
    <body>   
    <header>
    <main>
    <aside>
    <footer>
    <article>
    <section>
    <nav> 
    ```
    - Formatting Tags
    ```html
    <b>    
    <i>
    <u>
    <s>
    <strong>
    <em>
    <sup> and <sub>
    <pre>
    <code>
    ```
