# What is Node.Js ?
- In simple node js is **Run time invioment for JavaScript.** Build on the top if **V8 Engine** made by **C++**, we can called Node Js as wrapper also.

- Node js is the RTE for JavaScript which is **Single Threaded (In simple word only one worker who accually does work)**, still it is very fast because of Non-blocking Architecture and ASync nature.

- **Node.Js = Js + C++(For I/O Binding) + C language lisuv(For ASync nature)**
